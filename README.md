# Phishing Detection Extension – Proof of Concept

This repository contains the materials created for the FIU Senior Design project.  
The project includes a simple phishing‑detection demonstration using a web interface and a Node.js backend.

All files in this repository were created by the student team as part of the course requirements.

## Contents
- Source code (frontend and backend)
- User documentation
- Installation instructions
- Testing results
- Project poster
- Presentation slides
- Video recordings of the presentations

## How to Run
1. Install Node.js  
2. Open the project folder  
3. Run:
   npm install
4. Start the server:
   npm start
5. Open the browser at:
   http://localhost:3000

## APIs Used
- VirusTotal  
- AbuseIPDB  

## Notes
This is a proof‑of‑concept created for academic purposes only.
